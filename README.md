* 🛒 E-Commerce Sales \& Customer Analysis Using SQL



* &#x20;📖 Project Overview



This project demonstrates SQL skills by analysing an e-commerce database containing customer,categories, products, orders,order items and payment information. The project covers everything from database design to advanced SQL queries, providing business insights that can help an e-commerce company make data-driven decisions.The database was designed from scratch using DBfiddle and includes realistic sample data to simulate an online retail business.



* &#x20;🎯 Project Objectives



\- Design a relational database for an e-commerce business.

\- Create tables with Primary Keys and Foreign Keys.

\- Populate the database with realistic sample data.

\- Perform business analysis using SQL.

\- Demonstrate beginner, intermediate, and advanced SQL concepts.

\- Generate meaningful business insights from sales data.

* 🗂️ Database Schema



The project consists of six tables:



| Table | Description |

|--------|-------------|

| Customers | Customer information |

| Categories | Product categories |

| Products | Product details and prices |

| Orders | Customer order information |

| Order\_Items | Products purchased in each order |

| Payments | Payment details for each order |
